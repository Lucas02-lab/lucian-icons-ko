# lucian-icons-ko

움직이는 Lucian SVG 아이콘을 찾아 웹 화면에 적용합니다.

## 사용 예

> 기존 다운로드 버튼에 Lucian 아이콘을 넣고 실제 작업 상태와 연결해줘.

## Codex 설치

이 저장소 전체가 하나의 스킬 폴더입니다. 터미널에서 아래 명령을 실행합니다. 같은 이름의 폴더가 이미 있으면 덮어쓰지 않습니다.

```sh
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
git clone https://github.com/Lucas02-lab/lucian-icons-ko.git "${CODEX_HOME:-$HOME/.codex}/skills/lucian-icons-ko"
```

새 Codex 세션에서 `$lucian-icons-ko`을 지정하거나 위 예시처럼 요청합니다. 다른 에이전트의 설치 경로는 해당 제품의 안내를 확인하세요.
